# Accessoires locaux récupérés

Six PNG natifs auparavant hors du dépôt sont conservés ici sans modification. Le manifeste donne leurs empreintes, dimensions et observations visuelles. La composition de contrôle avec leur alpha natif confirme des objets isolés et entiers ; les halos de certaines vues brutes ne sont pas visibles dans cette composition. Leur emplacement dans les décors reste à définir, ils ne sont pas encore chargés par le jeu.
