## Périmètre de cette intégration

Les 64 combattants, 640 techniques, 540 costumes et 27 arènes sont ceux du runtime existant ; les 9 crossovers sont inclus dans les arènes. La campagne globale, les six connexions et les nouvelles phases de boss sont des propositions de conception. Cette passe produit de la documentation et du suivi, **zéro image, zéro nouvelle animation et zéro mode jouable supplémentaire**.

Le récit s’inspire du ton du Circus, tout en identifiant ses créations Encore. La fidélité canonique 1:1 n’est pas certifiée globalement. Les anciennes preuves de tests restent datées ; seuls les contrôles réellement exécutés dans cette passe sont rapportés comme courants.
