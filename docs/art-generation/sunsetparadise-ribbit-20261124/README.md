# Ribbit × Sunset Paradise — original Encore adaptations

Three original appearance families: hommage to Meggy, resident of Port Aurora, and amphibian body fusion. They are inspired crossover concepts for Encore, not official appearances or evidence of canonical 1:1 fidelity. Published Ribbit art anchors identity; existing Encore Sunset Paradise costumes supply local style references. Series context source: https://www.glitchprod.com/sunset-paradise (read 2026-11-24).

Each family contains eleven separately generated native PNG illustrations: selection, stance, intro, attack, heavy, hit, walk, jump, crouch, victory, defeat. These illustrations supply state poses, not complete frame-by-frame animation cycles. Every generation uses the built-in image_gen__imagegen tool with transparent_background:true, with exact prompt and references recorded per image. Full image_url results are retained in functions.store; generated native files remain in generated_images and the runtime copy is byte-identical, without cropping, recoloring or compositing. Python is used only for byte copying, hashing and read-only PNG/alpha inspection.

This batch recreates slots lost in an executor filesystem incident. Newly generated images are not byte-identical reconstructions of those lost outputs. Family stance seeds are visually inspected before being used as references for all other newly articulated poses. Native pixel dimensions, SHA-256 and Git blob SHA are recorded. Final inventory only declares complete after all thirty-three native copies pass verification.

Runtime activation belongs to the root integration agent and is gated on the final verified inventory. No runtime definitions are edited by the image author.
