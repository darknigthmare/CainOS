# Queenie — Gaslight District et Knights of Guinevere

Cette reprise complète six apparences originales Encore : les trois styles
`hommage`, `resident` et `fusion` de chacun des deux univers.

Huit PNG natifs ont été générés avec l’outil intégré `image_gen.imagegen` :
trois portraits Gaslight District, trois portraits Knights of Guinevere et les
deux gardes Knights résidente/fusion. Les quatre gardes déjà présentes sont
conservées à l’identique. Aucun dessin d’action ni cycle animé n’est ajouté.

Les portraits ont été générés avec leur garde comme référence. Les deux nouvelles
gardes utilisent le design existant et la référence Queenie officielle pour
l’anatomie. Les créations crossover ne sont pas des costumes canoniques.

`manifest.json` conserve les prompts, sources, sorties natives, chemins installés,
tailles et empreintes. Toutes les copies installées sont identiques aux sorties
natives ; aucun détourage, recadrage ou changement de pixels après génération.

`reviews.json` consigne l’inspection visuelle des six paires, les SHA-256 et les
mesures alpha. La couronne et les deux gants sont entiers dans les portraits ;
le corps entier et sa base sont visibles dans les gardes. La couleur des yeux,
les proportions et les détails de costume sont conservés entre chaque paire.

Ces vérifications portent sur les images sources. Les vérifications de rendu
dans le jeu, le manifeste hors ligne et les builds sont réalisées dans la passe
d’intégration globale. Aucune certification canonique ou pixel à pixel n’est
déduite du seul contrôle technique.
