# Queenie — Lackadaisy et Ultra Jump Mania

Ce dossier documente **neuf nouveaux PNG natifs** : les trois portraits
Lackadaisy qui manquaient aux gardes récupérées, puis trois gardes et trois
portraits Ultra Jump Mania. Les six apparences possèdent leur paire complète.

Les images ont été générées avec l’outil intégré `image_gen.imagegen`, en utilisant
les gardes, l’identité de Queenie et les références de costumes existantes.
Chaque fichier contient un seul personnage, sans animation et avec alpha natif.
Les pixels des sorties retenues sont copiés sans retouche par script.

- [Revues des six paires, empreintes et mesures alpha](reviews.json)

- [Gardes tropicales et éditions natives de fond](guard-receipts.json)
- [Portraits tropicaux initiaux](ultra-portrait-receipts.json)
- [Cadrage final du portrait Gardienne du verger](resident-portrait-margin.json)

Le portrait de la Gardienne du verger a reçu une correction native de cadrage
pour ménager une marge transparente sous le torse. Les trois gardes tropicales
ont été réexaminées après une demande de retrait de halo : les mesures du canal
alpha et les captures de production distinguent les RGB sous alpha nul d’un
fond réellement dessiné. Les motifs fins des feuilles, la couronne et les gants
restent complets dans les gardes.

L’hommage tropical conserve un petit nœud rose issu de la tenue Encore de
référence ; ce détail est documenté comme choix de crossover original. Les
six tenues ne sont pas des apparitions canoniques de Queenie. Leur revue dans
le jeu se trouve dans [la campagne Canvas commune](../canvas-all/visual-review.json).
