# Premiers crossovers des PNJ — Ribbit × Murder Drones

**Trois tenues actives, 33 PNG natifs transparents, 42 931 551 octets.** Les trois familles complètes utilisent le kit existant de Ribbit. Leur ajout dans le registre explicite ne crée aucun choix pour les 1 077 tenues PNJ encore absentes.

Les références de Ribbit et d’Uzi proviennent du [Pendantz officiel](https://glitchproductions.store/products/ribbit-pendantz-blindbox) et de la [figurine Uzi V2](https://glitchproductions.store/products/uzi-v2-animatez). Elles documentent les repères d’identité et de vêtement. Les designs combinés, proportions de jeu et poses sont originaux.

## Activation et revue

[Manifeste](generation-completion.json) · [Inventaire](asset-inventory.json) · [Revue native croisée des 33 images](review/independent/final-review.json) · [Galeries Canvas finales](../next-wave-20261120/README.md).

L’installateur vérifie les 33 fichiers, reçus, références et définitions avant de les activer. Le préfixe des 468 anciens costumes est conservé. Café Ribbit s’ajoute ensuite, puis les trois tenues PNJ. Les fichiers des 378 crossovers historiques restent inchangés, y compris le PNG de coup lourd déjà présent pour Jax en fusion Murder Drones.

L’harmonisation de huit poses Hommage et cinq poses Résident/Fusion a produit de nouvelles images natives. Les essais et reçus précédents sont archivés ; aucune correction locale de pixels n’a remplacé une génération. Les trois poses Hommage déjà conformes sont conservées avec une provenance explicite vers leur référence archivée.

**Les trois doigts ne sont pas une affirmation canonique.** Le Pendantz Iconic ne détaille pas les doigts ; la garde historique peut se lire avec quatre extrémités. Voir [l’addendum](hommage/hand-count-scope-addendum.md). La fidélité générale 1:1 et les cycles d’animation complets restent ouverts dans le [registre courant](../next-wave-20261120/remaining-work.md).
