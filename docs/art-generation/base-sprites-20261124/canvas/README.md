# Bases statiques — revue Canvas

24 familles, 48 dessins de base et 480 contrôles état/direction. Chaque contrôle utilise la même garde aux temps 0 et 600, puis avec mouvements réduits. Aucun dessin d’action supplémentaire n’est revendiqué.

Une seule famille est décodée par processus Node ; les processus sont strictement séquentiels. Le portrait et la garde sont distincts. Les planches proviennent du renderer de production, dans les deux sens, avec échelle uniforme et ancres conservées. Les données de combat ne sont pas modifiées. L’aperçu global est assemblé à partir de ces planches vérifiées.

Cette preuve native Skia ne vaut pas test navigateur ni certification canonique 1:1.

## Relecture visuelle séparée

Les 24 planches ci-dessous ont été ouvertes et relues individuellement : 18 par l'auteur des crossovers, quatre par l'auteur des premières compositions officielles et deux par le relecteur runtime. Cela représente 72 vues (portrait, garde droite et garde gauche), distinctes des 480 contrôles numériques. Les 24 familles sont acceptées pour la présentation statique observée. L'[agrégat visuel](visual-review.json) conserve les trois comptes rendus et les empreintes des images réellement relues. Les trois portraits Ultra Jump Mania sont volontairement en buste ; leurs gardes sont entières.
