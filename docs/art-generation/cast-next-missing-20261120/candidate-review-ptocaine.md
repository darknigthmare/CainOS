# PTO Caine — qualification du vêtement porté

Source officielle : [Beach Vacation](https://glitchproductions.store/products/digital-circus-animiniz-beach-vacation-series). La page énumère PTO Caine. `Beach_Series_Render_06.png` et `Beach_Menu.png` ont été inspectés à leur résolution native. Les lunettes menthe à verres jaunes, le haut-de-forme noir à bande rouge, le dentier rouge/blanc, les gants, la veste rouge, le pantalon et les chaussures sombres sont visibles.

Le catalogue ne contient aucun `ptocaine` ou `beachcaine`. Le dessin de Caine existant a été inspecté : sa tenue de maître de piste fournit le corps debout et le style du jeu. La différence retenue est l’accessoire porté (les grandes lunettes), pas l’invention d’un nouvel habit.

Le transat rayé, le verre et le décor sont exclus de cette variante mobile. Les parties masquées par la pose assise sont reprises du costume de base déjà dessiné ; aucune observation canonique supplémentaire n’est revendiquée. Les poses de combat sont des adaptations originales. L’illustration de sélection doit être validée visuellement avant de servir de référence aux dix autres slots.

Les originaux officiels et leurs empreintes se trouvent dans `references/beach-review-root/downloads.json`. La photographie n’atteste pas une présence dans un épisode.
